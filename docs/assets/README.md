# 教程配图说明

## 当前视觉规范

教程中的解释性插图使用用户最初提供的木鱼场景图作为**风格参考**：浅蓝灰背景、暖色桌面、绿色切割垫、白色SO-ARM101、黑色舵机和线缆、橙色强调、柔和产品级灯光、半写实三维教学渲染。初始场景只用于统一风格、材质、色彩和构图，不作为机械结构真值。

## 实拍结构基准

机械臂、夹爪、腕部相机、木鱼、敲棒和托盘以用户随后提供的七张本机实拍为结构基准，归档在[`reference-photos/`](reference-photos/README.md)。统一约束如下：

- 机械臂使用奶白色开放式3D打印连杆和支架，黑色矩形舵机外露，红白黑舵机线沿连杆布置，较粗的黑色相机线由黑色绑带固定；
- 夹爪是两根细长、渐缩的白色平行手指，能看到银色螺丝，只有指尖内侧带黑色防滑材料；
- 腕部相机是通过四个支柱水平安装在夹爪上方的小型裸PCB，不画成工业盒式相机；
- 木鱼是带双耳、粉色耳内、眼鼻、浅色口鼻区、脸颊纹和横向红色开口的橙色猫/虎造型，不画成橙色圆环；
- 敲棒为直木柄加单个乳白色软质椭圆头；托盘为带圆角和两端长槽的薄银色矩形托盘。

本轮按上述基准修正了十二张包含整机或任务物体的插图。`servo-closed-loop.png`只画舵机内部原理，`servo-bus-control.png`只画总线节点，不涉及整机、夹爪或木鱼，因此保持原图。

为避免图片生成模型写错中文，插图尽量不在画面内放正文，只保留必要的阿拉伯数字、箭头、状态图标和颜色分组；准确术语放在Markdown正文及图注中。

> 为SO-ARM101零基础教程绘制横向教学插图；匹配参考图的精致半写实三维产品渲染风格。使用暖米色桌面、绿色切割垫、浅蓝灰影棚背景、白色机械臂、黑色舵机和线缆、克制的橙色强调与柔和阴影。机械结构和线缆应合理，无品牌Logo、水印和乱码；除指定数字外不放文字。
