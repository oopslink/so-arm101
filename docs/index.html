HOW IT WORKS

人示范，数据记住，
模型再做一遍。

相机记录“看见什么”，关节状态记录“手臂在哪里”，动作标签记录“接下来怎么动”。π0 学习三者之间的关系，部署时再把预测动作交给底层控制器执行。

  1. 01TELEOPERATE人类示范Leader 遥操作 Follower
  2. 02RECORD同步采集图像、状态与动作
  3. 03FINE-TUNE训练 π0从数据学习动作策略
  4. 04DEPLOY真机闭环观察、预测、执行、再观察
