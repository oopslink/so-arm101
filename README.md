记录日期：2026-09-12。实验主线为Python 3.12 / LeRobot 0.6.1；不是适用于所有版本和所有机械臂的一键安装包。[只读核验](evidence/spark-readonly-audit.md)记录了实际环境、批编码补丁、数据数值检查和历史动作曲线；这些检查没有重新执行采集、训练或真机动作。

最重要的结论：**模型不是一个权重文件。训练生成的前后处理配置、归一化统计、tokenizer 和关节语义必须一起正确部署。** 本次“零位不动”的关键故障来自打包覆盖了后处理配置，而非已证明的“模型没学会”。

本仓库不包含模型权重、原始训练数据、标定文件或任何登录凭据。真机动作需要现场监护；不能把文档命令当成碰撞保护系统。
